# Vanessa Roof for Malcolm School Board

Static campaign website prototype built with plain HTML, CSS, and JavaScript.

## Preview locally
Double-click `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. Then:

1. Repository **Settings**
2. **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/ (root)**
6. Save

## IMPORTANT before public campaign launch
The visible footer currently says:

`Paid for by Vanessa Roof for Malcolm School Board.`

Nebraska's NADC treats candidate-committee websites as material subject to disclaimer requirements. If a candidate committee is paying for the website, the disclaimer generally needs the committee name plus a physical street address, or a permitted candidate-committee P.O. Box. The campaign should replace the footer's temporary wording with the exact legally appropriate payer/committee name and address before treating this as the final public campaign site.

Also confirm that the campaign has permission to reproduce the Malcolm Clippers logo on campaign materials.
